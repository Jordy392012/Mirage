A QUICK REALITY CHECK

What MIRAGE does today

MIRAGE is a browser-based analyzer with an experimental project-wide source-rewrite workflow. It does not compile firmware, run code, or measure execution time.

✓Works now
Import supported source files/ZIPs, scan code patterns, preview and apply several conservative source-rewrite candidates across loaded C/C++ files, inspect optimization hints for loops, math, serial output, allocations and buffers, undo eligible changes, export a project ZIP, estimate matched array sizes, and export a JSON report.
↗Next milestones
More validated optimization passes, compiler checks, ESP-IDF build integration, and on-device benchmarks.

All analysis runs locally in your browser. The optional ZIP library is loaded from a public CDN.
